# Changelog

## 0.1.0

Initial prototype: headings, text, buttons, images and spacers; drag reordering; block duplication and removal; text, alignment, color and spacing controls; mobile-width preview; WordPress page saving and frontend rendering. Includes editor and WordPress integration tests and a Docker development environment.

Known limits: linear layouts, no nested columns or template library, no breakpoint-specific styles, and no layout autosave or revision restoration.
